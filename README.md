🧾 Invoice Management System

📌 Project Overview

The Invoice Management System is a Java-based desktop application developed to simplify and manage the invoice generation process. It allows users to enter customer details, add products, calculate totals, apply discounts, and generate invoices in an organized format.

This project is developed using Java Swing for the graphical user interface (GUI), providing a simple and user-friendly experience.

🎯 Objectives

To simplify invoice creation and management.

To maintain customer and product details.

To calculate product amounts and invoice totals automatically.

To apply discounts during invoice generation.

To display invoices in a clear tabular format.

✨ Key Features

Customer Management – Enter customer name and contact details.

Item Management – Add product names, quantities, and prices.

Automatic Calculation – Calculate item amounts and subtotal automatically.

Discount Management – Apply discounts to the total invoice amount.

Invoice Generation – Generate a professional invoice with customer and product details.

Invoice History – View previously generated invoices during the application session.

User-Friendly Interface – Simple graphical interface developed using Java Swing.

🛠️ Technologies Used

Programming Language: Java

GUI Framework: Java Swing

Development Environment: Visual Studio Code

Database: Not implemented in the current version

▶️ How to Run the Project

Install Java JDK on your computer.

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open the terminal in the project folder.

Compile the Java program:

javac InvoiceManagementSystem.java

Run the application:

java InvoiceManagementSystem
